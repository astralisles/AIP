# Where documentation goes

- `README` (root): how a person runs AIP locally. Change only when a command a user types changes.
- `compiler/README.md`: short overview and the current feature list. No design essays here.
- `docs/design/<topic>[-T-<ticket>].md`: one file per design decision, question answered, or roadmap topic.
  Update the existing file for that topic; create a new one for a new topic.
- `docs/claude/<topic>.md`: instructions for Claude, imported by the root `CLAUDE.md`.
- `scripts/README.md`: one line per script, in sorted position.
- `tests/checks/README.md`: how to write a test check.
